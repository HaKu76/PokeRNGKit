# PokeRNGKit UI 设计契约

PokeRNGKit 的正式 UI 固定采用 Ant Neutral HakuStyle 工作台。该契约适用于所有
产品模块、全局工具和后续界面改动，不作为可选主题或临时 Demo 风格。

唯一完整规范见
[`PokeRNGKit Fixed UI Contract`](../.agents/skills/web-frontend-style/references/pokerngkit-ui-contract.md)。

实现基线：`src/styles.css` 的语义令牌与工作台外壳、`src/App.tsx` 的可搜索分组
侧栏、三态主题和右下角工具 Rail。`?demo=hakustyle` 保留为独立设计预览，不替代
真实 RNG 模块。

## RNG 面板逐项优化目标

第三世代定点乱数是后续 RNG 面板的紧凑布局参考。参考范围包括工作台密度、面板边界、
字段对齐和单一滚动责任，不要求所有模块复制同一种外层行列结构。每次只优化一个面板，
完成本地验证后单独提交并推送，不能通过全局覆盖一次性改变尚未核对的模块。

当前未完成目标只包含后续面板迁移：逐个核对并应用下列规则，每个面板完成后立即
本地验证、独立提交并推送。已经完成的第三世代定点乱数不再作为待办项重复列入目标。

- 模块专属布局和密度样式放在功能目录内的独立 CSS，由模块入口导入；共享 Select、
  MultiCheck、菜单定位和主题样式只保留跨模块语义，不引用具体 RNG 模块。
- 使用页面作用域和局部 CSS 变量控制密度，避免提高选择器优先级或追加跨页面全局覆盖；
  迁移一个面板时同步清理该面板仍散落在全局样式中的专属规则。
- 公共 `[class*="-workspace"]` 容器断点只能作为低优先级回退，并使用 `:where(...)` 消除
  选择器权重；模块 CSS 负责声明当前工作流的实际行列结构，公共断点不得覆盖模块布局。

- 生成器/检索器放在存档信息左侧，生成/检索命令保留在乱数信息面板左下角。
- 乱数信息、设置、筛选在桌面同一行；前两块固定为内容所需的紧凑宽度，容器宽度
  变化时只让最右侧筛选面板伸缩。窄视口再整体单列重排。
- Gen VI、Gen VII 的完整模块工作区固定使用“设置在上、结果在下”的外层顺序；
  `.stacked-module-workspace` 不参与公共中宽屏两列重排。设置区可以按模块需要组织
  内部字段，但不得用多个独立滚动列压缩控件或裁掉交互区域。
- 面板、标题区与结果区共享右边界。字段标签和控件按列对齐，控件宽度以实际最长
  内容为依据，避免无意义留白；等级、图鉴编号与宝可梦、分类使用相同左右边界。
- 输入框、`haku-select`、`multi-check-control`、分段标签和同行操作按钮统一为
  `30px` 高度，并同步收紧垂直内边距、字段间距和重复 IV 行高。共享选择器必须拥有
  相同边框、圆角、文本截断、状态样式，菜单宽度等于触发框宽度。
- 筛选面板内部结构保持稳定，面板伸缩时只改变右侧输入框和选择框宽度。六项 IV
  范围保持紧凑；完美个体值、完美个体数在异色/性格下方采用左标签、右输入框结构，
  并与上方选择框左右边界一致。
- 显示能力值、取消筛选放在个体值计算器左侧，三者处于同一底部操作行并对齐高度。
  筛选标题分割线与首行控件保留和其他面板一致的间距。
- 结果区紧接三块控制面板下方，并允许调整可用宽度。是否异色、性格、特性、觉醒
  属性等列按真实最长结果收窄；最后一列不显示多余右边界线。提示或警告放在结果
  标题右侧，不占用独立内容行。
- 下拉菜单不得越过触发框宽度；长内容在框内截断或换行。移除 `PokeFinder / Filter`
  等不服务于操作的信息，不使用冗余说明填充面板。

变更前必须读取 HakuStyle 契约；任何偏离 Ant Neutral、标准密度、224px / 64px
侧栏、无编号面板、候选控件和桌面悬停工具 Rail 的修改，必须先取得项目所有者的
明确决定。
