# 第三世代 Wild Generator（首轮）

当前野生模块提供第三世代前向野生生成。内置 Ruby、Sapphire、Emerald、FireRed 与 LeafGreen 的地点、陆地、冲浪、碎岩、旧钓竿、好钓竿和厉害钓竿遭遇表。

## RNG 顺序

实现对照 PokeFinder 4.3.2 `WildGenerator3::generate`：遭遇槽位、等级、性格、满足该性格的 PID，以及 Method 1/2/4 的 IV 调用顺序。支持同步、可爱魅惑、压力、磁力与静电首发特性；遭遇槽位使用上游 H 槽位权重。

## 当前边界

- 已包含：五个第三世代版本的地点遭遇表、Method 1、Method 2、Method 4、槽位、等级、性格、PID、IV、闪光、CSV 和取消。
- 物种名称来自 PokeFinder 4.3.2 的简中物种表，并按图鉴编号显示；该表采用神奇宝贝百科当前使用的简中名称形式，例如“妙蛙种子”“引梦貘人”“代欧奇希斯”。
- 未包含：沙狐乐园的额外 RNG、丑丑鱼格、未知图腾字母、Wild Searcher 和档案。
- 当前首轮直接在浏览器任务中分批让出事件循环，以便取消；尚未接入独立 Wasm/Worker 模块，不能作为大范围性能或上游一致性验收依据。

## 使用方法

1. 选择版本、遭遇类型与地点。
2. 选择首发特性；同步可额外指定同步性格。
3. 填写 Seed、推进范围和 TID/SID；性格筛选为空时保留所有性格。
