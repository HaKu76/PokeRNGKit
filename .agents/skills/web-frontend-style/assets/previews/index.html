怎样设计一套稳定的闪光追踪流程

从记录结构、状态反馈和中断恢复三个方面，整理一套适合长期使用的研究工作流。

2026-08-138 分钟阅读

先确定记录的最小单位

每一次遭遇都不是一张新的视觉卡片。界面只需要保留当前计数、概率条件和最近一次状态变化，让记录本身保持连续。

设计原则

用稳定的信息层级承载数据，只有独立记录和可操作工具才需要边界。

让中断可以恢复

主题切换、页面刷新和临时离开都不应该清空上下文。当前目标、筛选条件和计数状态需要通过明确的持久化策略恢复。
